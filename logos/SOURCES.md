# Logos des groupes

Logos récupérés le 13 novembre 2026 sur Wikimedia Commons (vignettes de 250 px de large), uniquement sous licence libre ou dans le domaine public. Les groupes absents de cette liste (SOC, LFI-NFP, DEM, HOR, NI) n'avaient pas de logo réutilisable sur Commons : le site affiche leur sigle sur fond de couleur.

Pour ajouter ou remplacer un logo : déposer `logos/<SIGLE>.png` (ou `.svg`, `.webp`), noter sa source ci-dessous, puis relancer `python src/prep.py`.
